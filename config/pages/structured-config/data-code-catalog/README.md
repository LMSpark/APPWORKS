# 编码目录场景

正式场景 `A133D679691178F192D7E9DA06829506` 使用当前服务的 Base_CodeDesign、Base_AppSystemList 和 Base_UserInfo。模型和字段定义保留在数据库，配置只引用身份并声明视图查询与级联。

应用选择绑定应用视图的 value 成员，按选中记录主键级联过滤编码 AppID；未选应用时目录为空。执行 AppWorks 的请求身份不作为被管理应用的默认值。名称查询、排序和分页由编码 DataView 承接，列表只读；设计操作携带选中的应用身份和编码 ID。

当前实服可读应用与历史编码 AppID 存在不匹配，记录在唯一实施台账中；配置不按显示名称猜测应用，也不放宽正式查询范围。完整设计器和规则维护仍须按独立编辑场景恢复，目录可加载不代表整页迁移完成。
