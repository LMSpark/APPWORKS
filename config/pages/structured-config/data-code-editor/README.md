# 编码设计场景

`pagedata.json` 引用实际服务场景 `868E62F90DB8118C74CDC9F6BCA61157` 的正式模型，不保存字段真源或运行数据。

输入 `applicationId` 表示被管理应用，`codeDesignId` 表示编码主记录；两者同时约束主记录。节点通过已读取主记录的选择级联查询，不能仅凭未确认归属的输入加载。父编码候选限定同一应用并排除当前记录。序号、分类、业务字段及初始值记录按需查询，分别按本次编辑视图提交。

`busTableRowid` 用于字段候选，`sequenceNodeId` 用于初始值记录。主记录和节点保存不得夹带规则目录或初始值的待提交修改；不同提交范围不承诺跨请求事务。

当前配置已接入已有设计的主记录表单及节点表格，名称和固定字符串节点沿正式 DataSet 保存，编辑取消及目标切换沿同一视图执行。日期、父编码规则直接编辑原节点视图，取消复用原生字段检查点；顺序号目录独立维护并保存后选择写回节点，主设计保存不提交目录。原单字段文件视图和 GetCodeDesignDetail/SaveCodeDesign 客户端已删除。完整业务表选择、新建主记录与节点、分类规则、例码及初始化维护仍未恢复，不能据此宣称编码设计整页完成。实际模型中的节点 `description` 为非输出字段，完整描述字段的恢复仍是开放项；本配置不绕过正式输出字段合同。例码刷新和初始化数据命令另须核实际服务能力，不能从模型可读推断命令已可用。
