# 工作流目录场景

目录场景：`5E9676B1E38860B023921F48FB4370DE`。

## 数据边界

- `Base_WorkflowDefinition` 与 `workflowStatus` 通过统一场景加载器装配。
- 名称、编码、状态、描述与触发设置按正式 DataView 字段权限读取、编辑和保存。
- 编辑操作限定定义 ID 和当前命名视图；目录切换不得借用旧草稿、查询结果或权限。
- 工作流设计通过同一导航节点打开独立设计场景，不复制定义或节点数据。

## 当前缺口

- 正式新增仍受现有服务的“先有业务定义、再分配编码”合同约束，前端不能创建随机编码或占位定义。
- 保存回读与目录刷新是两个结果，不能用刷新成功替代保存回执。
- 服务状态枚举、调度与浏览器整页验收仍以[唯一删除记录](../../../../notes/data-space-retirement-ledger.md)为准。

## 维护规则

- 不在目录页重新实现查询、权限、保存或编码分配。
- 不用本地 JSON、历史截图或旧探针结果代替正式运行时响应。
- 设计器入口、模型引用和场景配置变更后运行对应的页面、数据空间和工作流回归。
