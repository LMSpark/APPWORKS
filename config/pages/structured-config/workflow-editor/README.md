# 工作流独立设计场景

正式场景：`0DD8D28D462F51C5790AA6FBFAE39366`。调用输入为 `workflowId`。

## 数据边界

- 定义、节点、连线、开始参数与节点授权通过所属 DataView 读取和编辑。
- 节点模型来源按节点类型精确解析；不能把节点配置 JSON、模型身份、字段身份或运行输入混为同一对象。
- 布局文件只承接坐标和连线呈现，仍通过原 `WorkflowLayout` 文件资源与同一 DataSet 保存。
- 保存只提交本次明确目标，不夹带其他节点、模型、关系或文件草稿。
- 结果未知时保留原捕获并只核验原请求；不能用当前查询结果自动证明未生效或重放写入。

## 组件与配置

- 标准图、表格、表单、过滤表达式和 JSON 字段消费正式 DataView。
- merge 输入层级来自真实 `input_mapping`；字段编辑只写回所选输入路径。
- 来源选择、移除、连接类型和条件编辑复用原节点输入基线，拒绝后缀猜测、孤立引用和循环。
- 标准容器与字段组件负责编辑、取消、权限和页面生命周期；页面不再维护第二套查询或草稿真源。

## 当前缺口

- 正式目录新建及完整编码分配合同仍须由服务能力确认。
- merge 的部分连接/输出语义和部分执行函数不能由前端补算来伪造。
- 配置回读、文件保存或测试通过，不单独证明浏览器 1:1、定时执行或真实业务消费已验收。
- 当前完整进度、服务缺口和实服边界只以[唯一删除记录](../../../../notes/data-space-retirement-ledger.md)为准。
