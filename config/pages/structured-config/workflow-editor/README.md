## 缺失开始和结束边界

设计器读取完整的当前工作流节点后显示边界缺失。读取不创建记录；“补齐缺失边界”只在原节点DataView暂存本次缺少的开始/结束节点，名称分别为“开始”和“结束”，类型为参考定义的API_CALL。已有多个结束节点保留，重复开始或非法位置明确报错。边界不通过普通节点类型选择或删除入口维护。

保存和取消只定位本次分配ID，不包含同视图后来添加的节点。共享DataSet提交捕获承接未知结果；有效回执后仍须独立回读全部本次字段。回读失败保留原核验入口并阻止关闭。无效回执须明确读取并采用当前结果；完整可读结果与原意图不同，可明确结束原意图并保留正式记录，不再派发、不删除记录，也不标记原意图已确认。

补建开始节点不会另建或改写输入参数。已有输入应选中开始节点，沿“保存开始参数”的既有命令确认并同步开始输出。API_CALL两端的实际整流执行须依据独立实服证据，配置回读不能证明执行支持。当前进展及服务差距只在唯一台账核销。
