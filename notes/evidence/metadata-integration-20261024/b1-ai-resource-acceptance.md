## 交付边界

- `AiTurnResource` 在调用方原 DataSet 上装配 Agent 目录、创建命令、轮次状态、取消命令四个 DataView。查询和提交只走现有 SPARK data 绑定；不提供审批、客户端工具执行或独立保存入口。
- 创建 ACK 与生成完成分别确认；取消 ACK 与停止状态分别确认。未知创建没有可信 turnId 时保留原 capture，不重发 POST。已知取消目标仅以正式 GET 核验。
- HTTP 5xx、网络失败及损坏回执保留 unknown；本地输入校验不产生 HTTP 或 unknown。原 `LowcodeClient` 仅新增可选保留 HTTP 错误与逐请求 retry 参数，原调用默认语义不变。
- 实例销毁或 guard 失效后须重新装配，迟到结果不能借给新目标。目录冲突先完整检查，命令保存指定视图，原字典修改不参加 AI 命令提交。
