# 数据空间视图配置：主控验收断点

当前为实施中，不能据此宣称整页或输入级联完成。准确文件和验证范围以主计划顶部本闭环为准。

## 已核事实

- 改前字节见 manifest.json 及对应路径副本。目标空间正式 pagedata 缺失见 preflight.json；本轮尚未写远端文件。
- 共享配置继续由编辑工作区 ScenarioViewFile 持有；PageRuntime 只绑定脏状态及通知，不拥有或销毁共享文件。
- 已有模型来源、无键读取与关系表达式闭环冻结。本轮模型候选取设计页正式查询，选中后读取正式字段；保存和预览沿现有工作区与装配入口。

## 主控退回项（待执行者修复及复验）

1. 首次绑定已有 dirty 文件要发内容变化通知；pending/unknown 即使正文等于旧基线仍 dirty。
2. 远端接受操作等待期间另一保存可改变本地基线但不改变正文；本地修订或等价检查须覆盖该状态变化，拒绝旧远端结果覆盖新保存。
3. create/stage 等待正式模型时页面 abort/reload 不得留下迟到本地修改；已派发保存的 owner 结算要继续。不能只在桥返回后检查代次。
4. 预览用真实查询返回的可见/隐藏/脱敏状态组织显示，失败也销毁临时 DataSet。空装配夹具不证明这条路径。
5. 未点“应用”的表单编辑也须用已有 PageLocalDraft 保护及恢复；文件 owner 的 dirty 不覆盖这种尚未应用编辑。
6. 已被其他模型使用的稳定表名不能通过“新建表绑定”混入当前选择；预览服务也须核对明确模型身份。
7. 清除显式 pageSize/布尔设置与不修改设置必须可区分；选择默认后保存重开不应恢复旧显式值。
8. 新增视图合同内部类型不额外 export 无消费者符号。

当前基础配置选择联动不等于完整多父字段运行输入级联，也不等于完整配置设计公共级联机制。后续仍要把父字段集合、目标值及候选项更新规则纳入正式配置与公共执行逻辑；不能以这一页脚本联动宣称该目标完成。
