## 实际改变

- field 级联父输入现在是 tableName/viewId/可选 field/parameter。字段值通过 DataMember.Value 读取，省略 field 时为选中主键数组；允许跨视图和多父值，空数组不转换成未提供参数。
- 删除 field 的 rowMode 与运行地址 rowId，旧输入明确拒绝。绑定层定位指针、编辑覆盖和数据权限，执行层比较最终值快照；等值换指针不重复查询，旧请求不能写到新指针。
- 新选项按 retain/clear/retain-valid 处理子值，子值实际变化沿现有编辑事件继续下游。保留取消、失败、迟到响应、用户中途编辑、销毁和读写权限约束。输入失效再恢复可以重新查询，初次未加载不能当成已确认空选择。
- 目标显式 valueFormat=native/selection-string；选项视图自身是 valueField/labelField/selectionDelimiter 的配置源。内部 SelectionValue 编解码由原 SelectionDelegate 和值绑定共用，保留 DataView.value 公共字符串合同。普通字符串不猜拆分，数组保留数组，复合选择值沿原冒号编码。
- 跨表父输入的改名、删除引用检查与撤销重做已覆盖；未增加另一套保存 owner。
