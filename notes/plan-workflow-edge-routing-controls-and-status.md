## 技术方案

1. 将设计专属数据收束到 `line.data.visual`，包含有限线型和按路径顺序排列的绝对画布坐标控制点；保留既有 `line.type` 业务字段。
2. 旧稿缺少线型、控制点或 dock 时分别按正交、空数组和 `0` 读取；保存前规范化所有主图及嵌套图。
3. 端口按顺时针编号；自动 dock 仅在右/下 source 和上/左 target 候选间计算最短距离。
4. 自定义 edge 根据起点、控制点序列和终点构造路径：
   - 正交：各锚点之间生成水平/垂直折线路径，并使用常规圆角折点。
   - 直线：按锚点顺序生成分段直线。
   - 贝塞尔：以锚点序列生成平滑曲线路径。
5. 控制点采用主流交互：双击线段在命中位置插入；拖动实时更新；选中后键盘删除或双击删除；清空后恢复无控制点自动路径。
6. 节点移动时端点随 Handle 更新，绝对坐标控制点保持原位；用户可继续拖动调整。
7. 运行状态仅投影为 edge class、动画、颜色和非阻断点击的图标，当前默认 idle；预留显式状态表输入，不接粗粒度 SSE。

## 兼容性

- 旧稿无需迁移即可打开；首次保存后缺失 dock 规范化为 `0`。
- 未设置控制点的连线保持自动路径；已有未知字段原样保留。
- 设计视觉数据不进入 definition，不改变执行顺序、端点业务语义或运行契约。

## 风险项

- Vue Flow 内置 edge 不支持任意控制点，需要局部自定义 edge；不得扩展为新绘图库或通用画布重构。
- 正交路径经过自由控制点时需确定入射方向；采用最短轴优先并保持稳定顺序，避免拖动时路径跳变。
- 贝塞尔多点拟合可能过冲；使用局部平滑策略并限制控制柄，不越过相邻锚点范围。
- 多线共享 Handle 可能视觉重叠，本次不增加自动避让。
- 页面文件较大，只实施方案内局部能力，不顺手拆分或重构。

- 若必须新增后端事件、依赖或 definition 契约，停止并修订方案。
